# 环境复现

更新时间：2026-08-13

项目不使用整份 Conda `pip freeze` 作为跨机器锁文件，因为 PyTorch、CUDA、bitsandbytes 和 vLLM 必须与目标 GPU 驱动匹配。Python 基础依赖采用最小版本区间，前端由 `package-lock.json` 精确锁定。

## CPU / 开发环境

适合数据清洗、规则、评测、API helper 和单元测试，不运行 14B：

```bash
conda create -n jobmatch-dev python=3.11 -y
conda activate jobmatch-dev
pip install -r requirements-dev.txt
ruff check .
pytest -q
```

`constraints/base.txt` 固定主要库的兼容大版本，避免半年后直接漂移到不兼容 API。

## GPU / 推理环境

先按目标驱动从 PyTorch 官方矩阵安装合适的 CUDA wheel，再安装：

```bash
conda create -n jobmatch-infer python=3.11 -y
conda activate jobmatch-infer
# 示例：先安装与目标驱动兼容的 torch，不机械复制此机器的 CUDA wheel。
pip install -r requirements-gpu-inference.txt
```

Transformers 路径需要 `torch + transformers + peft + bitsandbytes`。vLLM 路径应另外选择与 torch/CUDA 匹配的 vLLM 版本，并在压测报告记录版本；不把一个宿主机特定的 vLLM wheel 写进通用约束。

当前已验证快照：Python 3.11.15、PyTorch 2.11.0+cu130、Transformers 5.8.0、PEFT 0.19.1、bitsandbytes 0.49.2、NVIDIA L20 46,068 MiB。它是复现参考，不是所有机器的强制组合。

## GPU / 训练环境

```bash
conda create -n jobmatch-train python=3.11 -y
conda activate jobmatch-train
# 先安装与宿主机兼容的 PyTorch CUDA wheel
pip install -r requirements-gpu-training.txt
```

训练额外依赖 `datasets`、TRL、kernels、Liger 和 scikit-learn。正式训练前仍必须通过 readiness gate；环境可用不代表数据允许训练。

## 前端环境

```bash
npm ci --prefix frontend
npm run build --prefix frontend
```

Vue 3 和 Vite 的精确依赖树由 `frontend/package-lock.json` 锁定，构建产物位于 `frontend/dist/`，不依赖 CDN。

## 半年后恢复检查

```bash
python --version

nvidia-smi
ruff check .
pytest -q
npm ci --prefix frontend

```
