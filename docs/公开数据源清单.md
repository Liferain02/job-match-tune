# 公开数据源清单

更新时间：2026-08-09

> 状态说明（2026-08-09）：这是数据源与许可证核验清单，不是实时可用性承诺。下载前应重新确认上游版本、许可证、个人数据处理条件和当前配置路径。

## JD / 招聘数据

1. `edwarddgao/open-apply-jobs`
   - 类型：公开招聘职位聚合
   - 规模：百万级
   - 当前状态：三个技术岗位分片已固定 revision 和 SHA-256；数据集包装为 MIT，但数据卡说明岗位正文版权属于各雇主，仅主张研究/产品场景的合理使用
   - 使用边界：`research_evaluation_only`，保留在 raw 审计层，不进入默认训练池，也不作为 holdout
   - 链接：<https://huggingface.co/datasets/edwarddgao/open-apply-jobs>

2. `wangzihaogithub/job-educational-parser-dataset-08-0-0805`
   - 类型：中文岗位描述 -> 学历要求
   - 规模：288,627
   - 当前状态：数据集声明 Apache-2.0，文件已固定 revision 和 SHA-256；上游明确 train/validation/test 不是人工标注，且没有完整说明岗位正文来源
   - 使用边界：`weak_supervision_only`，不称为人工 gold；上游 validation/test 也不当作本项目 holdout。最终 JD 质量集对该来源家族设置 40% 上限
   - 链接：<https://huggingface.co/datasets/wangzihaogithub/job-educational-parser-dataset-08-0-0805>

3. `Job-SDF`
   - 类型：中国招聘技能需求多粒度数据集
   - 规模：基于 10.35M 公共招聘广告构建
   - 当前状态：可作为技能词表/趋势研究参考，不直接适配当前 JSON parse 任务
   - 链接：<https://job-sdf.github.io/>

4. `Chinese-SkillSpan`
   - 类型：中文招聘文本 L/K/S/T 四类技能跨度标注
   - 标注：LLM 初标后由专家句级复核，覆盖中文招聘技能抽取
   - 当前状态：已下载并按 SHA-256 固定版本；剔除 86 条无法还原原句的破损标注，去除 split 内重复和跨 split 重复后得到 4502 条、12804 个跨度
   - 使用边界：发布页未找到明确数据许可证，因此只进入内部评测，不进入 SFT/DPO，也不随仓库分发
   - 链接：<https://sites.google.com/view/cn-skillspan-resources>

5. `SkillSpan`
   - 类型：英文招聘文本 hard/soft skill 专家跨度标注
   - 规模：上游 11543 句；严格处理后保留 8784 句、9316 个跨度
   - 当前状态：MIT 许可证和 GDPR 去标识说明明确；已固定到上游 commit 并清理重复、1 条非法 BIO 标注及跨 split 重复文本
   - 适用：英文/跨语言技能抽取对照评测，不直接混入当前中文多任务 SFT
   - 链接：<https://github.com/kris927b/SkillSpan>

## Resume / 简历数据

1. `OhMyKing/FairCV`
   - 类型：中文模拟简历
   - 规模：100K<n<1M，仓库存储约 6.86 GB
   - 当前状态：已接入轻量采样入口，当前拉取 1000 条进入 resume 候选池
   - 风险：字段口径和当前 schema 需要映射，且包含偏见研究变量
   - 链接：<https://huggingface.co/datasets/OhMyKing/FairCV>

2. `PassbyGrocer/resume-ner`
   - 类型：中文简历 NER
   - 规模：train 3821 / validation 463 / test 477
   - 当前状态：已下载 train parquet，共 3821 条；17 个数字标签已按上游 schema 解码为 BIO 标签
   - 风险：是 token classification，不是完整 JSON 结构化标签；3375 行出现姓名、联系方式、地点、机构或民族等敏感实体，且数据卡没有交代原始采集与脱敏过程，因此维持 `audit_only`，不混入 resume_parse SFT
   - 链接：<https://huggingface.co/datasets/PassbyGrocer/resume-ner>

## JD-Resume Match / 匹配数据

1. `med2425/resume-job-fit-merged-v1`
   - 类型：简历-JD 匹配分类
   - 规模：93,733
   - 构造方式：合并两个数据集、生成跨域配对，并由 Qwen2.5-32B 教师标注
   - 当前状态：已修正本地导入字段 `jd`，但上游没有声明许可证，因此仅允许本地审计
   - 适用：匹配任务结构和噪声分析参考，不进入默认训练池
   - 风险：主要是英文、合成/教师标注占比高，不能视作人工 gold
   - 链接：<https://huggingface.co/datasets/med2425/resume-job-fit-merged-v1>

2. `cnamuangtoun/resume-job-description-fit`
   - 类型：简历-JD 匹配
   - 当前状态：上游没有数据卡、许可证和来源说明；仅保留审计入口，不进入训练池
   - 链接：<https://huggingface.co/datasets/cnamuangtoun/resume-job-description-fit>

3. 天池「智联招聘人岗智能匹配」2019（竞赛编号 `231728`）
   - 类型：中文脱敏简历、职位，以及浏览/投递/HR 认可行为
   - 价值：是真实双边行为信号，ConFit / ConFit v2 / ConFit v3 均将其用于人岗检索或重排实验
   - 当前状态：官方页面仍要求登录和报名下载，没有找到允许二次分发或通用训练的开放许可证
   - 使用边界：取得主办方书面授权、保存协议版本并完成隐私审计前，只作为候选源，不下载、不导入、不再分发
   - 链接：<https://tianchi.aliyun.com/competition/entrance/231728/information>

## 当前取舍

- 默认高质量训练仍然优先：
  - 中文公开官网 JD
  - 可控人工/模板 resume
  - 可控配对 match 数据
- 外部公开数据集当前主要用于：
  - 扩技能/字段边界
  - 扩简历样式覆盖
  - 扩匹配任务弱监督或对照实验
- 在没有完成 schema 映射和质量审查前，不直接混入默认 `SFT` 主集
- 匹配公开数据还必须满足 `license_status=confirmed`、训练用途获准、来源可追溯三项门禁；文件存在不再等于可训练
- JD 外部源同样必须显式满足 `training_eligible=true` 和允许训练的 `intended_usage`；候选池、弱结构池和补充池都执行该门禁
