## 请求是怎样执行的

### JD/简历解析

API 先限制输入长度，再把文本放进带严格 JSON 约束的对话模板。模型输出经过三层处理：去除 thinking 文本、容错修复 JSON、按 Pydantic 字段和业务规则归一化。归一化会处理方向别名、学历/年限、技能证据、JD 职责与要求边界、简历优势标签等。

修复层的原则是“只恢复文本中已有证据”，不能凭常识补全技能。这一层既提高结构可用性，也造成 Raw 与 Product Final 的明显差异，因此评测必须分层报告。

### 人岗匹配

规则引擎总分 100：方向 20、技能 45、学历 10、年限 15、项目证据 10。技能按命中比例计算；等级阈值依次为 85/65/45。项目加分只接受项目或实习行中的显式技能证据。学历按等级比较，年限会排除毕业年份、届次等日历语境。

输出中同时保留布尔硬条件、命中/缺失技能和分项证据。解释模型接收的不是原始材料和一个空白问题，而是规则结果，因此它的职责是忠实表述，不是重新裁决。

## 推理后端取舍

### Transformers

默认路径使用 4-bit 加载和进程内生成锁。优点是依赖简单、适合单卡展示，缺点是请求串行，不能把同一次 Match 的 JD 和简历解析真正并发。对显存紧张、低 QPS 演示，这是更稳妥的默认值。

### vLLM

vLLM 通过 OpenAI 兼容接口提供服务，使用 JSON Schema 约束输出和 semaphore 控制并发。并发槽不少于 2 时，JD 和简历解析可同时提交；批量接口也使用受控并发。它更适合吞吐和在线服务，但需要额外服务、显存预算和压测。

因此“哪个默认更好”不是模型质量问题：本地低并发用 Transformers，稳定部署和批量吞吐用 vLLM。当前仓库没有已冻结的 vLLM 性能报告，不应宣称具体加速比。

## 文件和 OCR

文件层支持文本、DOCX、PDF 和图片。PDF 会判断可提取文本、扫描件和弱文本；OCR 可接 RapidOCR/PaddleOCR，也允许上传 sidecar 文本。归一化模块再恢复教育、项目、技能等常见段落。上传限制为 10 MiB，正文限制为 20,000 字符。

隐私层识别电话、邮箱、微信、QQ、身份证、年龄、姓名语境，以及性别、婚育、户籍、生日、民族、住址、健康、政治面貌和个人账号等字段。训练数据构建会删除或脱敏这些信息。

## API 与前端

API 包括健康、预热、状态、单条解析、匹配、批量解析、批量匹配和文件解析/匹配。前端是由 Vite 本地构建、package-lock 锁定依赖的 Vue 3 单页应用；可切换 JD、简历、匹配和单条/批量模式，展示结构化与原始结果，并复制 JSON 或下载 Markdown 报告。

这种实现适合原型：Vue/Vite 依赖由 lockfile 固定，启动脚本先构建再用静态服务器托管。当前仍没有真实浏览器端到端测试，也不能直接等同于生产前端。

## 训练实现

当前主配置以 Qwen3-14B 为底座，QLoRA 使用 4-bit NF4、double quant、bf16 计算，LoRA `r=8`、`alpha=16`、`dropout=0.05`，覆盖 attention 与 MLP projection；最大序列长度 768，单设备 batch 1、梯度累积 16、1 epoch、学习率 `1e-4`、cosine 调度。

SFT 使用对话 JSON、模型 chat template、`assistant_only_loss=True`、`packing=false` 和 DFT loss。DPO 从已训练 adapter 继续，最大长度 1024、学习率 `5e-6`、`beta=0.1`。执行脚本前还有 readiness gate；DPO 额外要求显式环境开关，避免无证据续训。

每次正式训练应生成 run manifest，记录 Git 状态、配置哈希、数据文件行数/哈希、来源分布、readiness、环境和命令行，以便把模型结果与输入事实绑定。

## 并发为何不是无条件开启

JD 和简历在语义上彼此独立，当然可以并行；限制来自推理后端。Transformers 在同一 GPU 上并行调用可能同时争用显存和非线程安全生成状态，所以实现使用锁。vLLM 本身负责调度批处理，才在容量门禁下并发。这是运行时资源选择，不是业务流程必须串行。

## 现有测试边界

测试覆盖数据 builder、分组切分、泄漏、隐私、规则、后处理、评测、API、文件解析、run manifest 和前端报告 smoke。仓库当前没有 CI 配置，也没有冻结的真实浏览器端到端或 vLLM 压测结果，因此应表述为“本地自动化测试覆盖”，不表述为“生产验证”。
