## 三种准备路径

### 时间只有两小时

读第1、7、9、12篇。目标是能讲清：为什么不是让 LLM 直接打分、为什么历史评测会污染、为什么实体级切分重要、为什么训练最终被门禁拦住。

### 有一天完整准备

先按顺序读1～14篇建立全貌，再读15～22篇中的核心深读章。至少手算一次第17篇的评分、手画一次第18篇的并查集、复述一次第19～20篇的两个目标函数；最后按第11篇做不看稿演示，并按第22篇随机挑一个故障现场定位。

### 面试前十五分钟

只看第12篇的数字和禁用表述，再复述第1篇的30秒版本与第10篇的三个 STAR 故事。

## 面试中的总原则

- 先讲问题和约束，再讲技术名词。
- 明确区分模型输出、确定性后处理和产品最终结果。
- 指标必须同时说数据规模、评测层级和适用边界。
- 主动承认真实 Resume、真实 Pair 和业务 outcome 不足。
- Readiness=false 是项目结果，不是需要隐藏的失败。
- 不把启发式分数说成录用概率。
- 不把已检查后的1.0回归说成新的盲测泛化。
