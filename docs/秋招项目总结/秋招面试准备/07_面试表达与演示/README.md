# 面试表达与演示

本目录负责把前六个目录的技术内容转化为可口述、可演示材料。

1. [高频追问与四层回答](01_高频追问与四层回答.md)：从基础问题到连续深挖。
2. [简历素材、STAR 故事与口述稿](02_简历素材_STAR故事与口述稿.md)：简历项目描述和不同长度讲述。
3. [现场演示、代码导览与故障预案](03_现场演示_代码导览与故障预案.md)：演示顺序、失败降级和代码入口。
4. [数字、术语与可信表达速查](04_数字_术语与可信表达速查.md)：面试前快速复习和禁用表述。

这些材料用于输出，不替代源码理解。遇到追问应回到[技术难点与解决过程](../06_技术难点与解决过程/README.md)。
