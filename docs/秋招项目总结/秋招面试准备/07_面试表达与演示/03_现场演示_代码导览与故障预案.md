## 三、SSH 访问

若个人电脑先登录登录节点，再进入 gpu03，需要两层本地转发。

个人电脑到登录节点：

```bash
ssh \
  -L 5174:127.0.0.1:5174 \
  -L 8000:127.0.0.1:8000 \
  用户名@登录节点地址
```

登录节点到 GPU 节点，同时保留原代理反向转发：

```bash
ssh \
  -R 7897:127.0.0.1:7897 \
  -L 5174:127.0.0.1:5174 \
  -L 8000:127.0.0.1:8000 \
  gpu03
```

浏览器打开 `http://localhost:5174`。`-R 7897` 只是让 GPU 节点使用代理，不会把项目端口送到浏览器。

## 四、推荐演示 Case

使用已冻结且结果正确的 `match_eval_002` 作为稳定示例，但口头说明这是回归演示，不是新测试。

JD：后端开发，要求 Java、Spring Boot、MySQL、Redis、Kafka，本科及以上，三年以上。  
Resume：后端目标，硕士，具备 Java、Spring Boot、MySQL、Redis、Docker，有订单中心和限流治理，但没写三年以上。

预期重点：

- 方向 exact；
- 学历满足；
- 经验不满足，因为无三年明确证据；
- 命中 Java/Spring Boot/MySQL/Redis；
- 缺失 Kafka；
- 历史为“较匹配”，分数是启发式，不是概率。

## 五、2分钟演示脚本

### 0～20秒：输入

展示 JD 和 Resume，说明系统支持文本与文件；今天用文本避免把时间花在上传。

### 20～50秒：结构结果

点击匹配后先指向 JD Parse 和 Resume Parse。强调两边独立生成，中间不是直接出现一个分数。

### 50～90秒：规则

展示命中/缺失、方向、学历、经验和分项。重点解释“没有明确三年证据，因此经验 false”，以及“启发式匹配分数”标签。

### 90～120秒：解释与原始 JSON

展示解释只能基于 Rule Result，再切到原始 JSON 指出 `岗位方向关系`、`技能证据`、`匹配分项` 和 `评分策略`。结束时说明 Raw/Normalized/Product 三层评测。

## 八、面试官可能让现场修改什么

### 新增一种技能 alias

先说明需要 canonical 与 alias，补正例和假阳性，再改 `label_schema.yaml`；不能只在规则引擎写字符串替换。

### 修改评分权重

通过构造新的 `MatchScoringPolicy`，权重和为100且阈值有序；强调没有业务数据时修改只是产品假设，不能称校准。

### 增加新方向兼容

先定义 leaf pair、双侧职责 signal、最小共享技能和反例；不能直接 alias。

### 支持新文件类型

需要同时增加 extension、content detection、真实 decode、提取器、错误码和测试；不能只在 accept 属性里加后缀。

## 九、故障预案

### 模型资产不存在

不要现场下载14B。使用录屏、冻结 JSON 或只做代码导览，明确大资产不随 Git 分发。

### 首次加载很慢

提前 warmup；若已开始，展示日志并讲模型生命周期，不反复点击。

### CUDA OOM

确认 `JOBMATCH_LOAD_4BIT=1` 和 GPU 占用；不要随意 kill 共享节点进程。必要时停止现场推理，使用保存结果。

### 页面能开但 API 未连接

检查两层8000端口转发和 `/health`；只转5174只能拿到静态页面。

### 前端空白

执行 `npm ci --prefix frontend` 和 `npm run build --prefix frontend`，检查 frontend log；浏览器不需要外部 CDN。

### 端口占用

先 `bash scripts/serve/stop_project.sh`，再用 `ss -ltnp` 确认占用者，不批量杀进程。

### 输出 JSON 失败

展示 raw output 与 error，解释系统不会在解析失败后继续生成看似可信的评分。失败本身可以用于说明可观测性。

## 十、录屏方案

秋招建议准备一段2～3分钟本地录屏：

1. 页面与服务状态；
2. 填充示例；
3. 执行匹配；
4. 展示结构、分项、解释和原始 JSON；
5. 最后放一页架构图和指标边界。

录屏不要包含用户名、服务器地址、真实简历、模型绝对路径或个人信息。它是现场故障备份，不替代自己讲代码。

## 十一、停止服务

```bash
bash scripts/serve/stop_project.sh
```

停止脚本会读取 PID、验证命令与项目路径，优先 TERM，超时才 KILL，避免误杀其他用户进程。

## 十二、演示成功标准

成功不是接口返回最快，而是面试官能在两分钟内看到：模型抽取、规则判断和解释是三个不同层级；你能指出每个结果的证据、限制和代码位置。
