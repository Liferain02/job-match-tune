# 发现但未处理的技术债

更新时间：2026-08-13。本页区分已解决、部分解决、外部阻塞和刻意不解决，避免把完成项长期挂成债务。

## 已解决

- JD 必备技能不再从整段文本扫描：要求/职责/加分/其他证据已分离，模型字段不再等于事实。
- `Py test`、`Py thon`、`Kubernet es`、`C + +`、`Node . js` 等已在已知词表内有界恢复，并有假阳性测试。
- 方向不再用宽泛 alias 返回单一 bool，已输出 exact/compatible/mismatch 与兼容证据。
- 文件上传已在 OCR/模型前检查大小、扩展名、魔数、容器结构、图片解码和文本编码。
- 前端已从 CDN 改为 Vue/Vite 本地锁定构建，并提供静态 smoke test。
- 规则分已标记 heuristic，界面称“启发式匹配分数”；解释评测已拆结构一致与证据 grounding。

## 部分解决

- 技能词表能处理常见 OCR 断字，但不能恢复任意拼写错误；只有独立错误反复出现才扩词。
- 方向兼容有最小 taxonomy 和证据门槛，但行业/岗位覆盖有限。
- 非标准 JD section 仍可能让必备技能少召回；保守过滤优先于把职责误算硬要求。
- 前端有锁定构建和 smoke test，但没有真实浏览器 E2E。
- 基准覆盖五类请求、并发、批量和 GPU 快照，但 API 未暴露 token usage 时不提供 tokens/s。
- 内容校验能拒绝常见伪装/损坏文件，但不是恶意文件沙箱。

## 外部条件阻塞

- Resume 独立来源不足；4,798 个 Match Pair 全为规则合成；显式年限样本缺“满足”正例。相关训练 readiness 保持 false。
- Preference 缺足量真实人工 chosen/rejected 和独立人工 holdout，DPO 维持暂停。
- Gold V1 仅 25 条且已被查看，只能做历史回归；新的泛化结论需要独立盲标 V2。
- 启发式权重和 85/65/45 阈值没有真实招聘结果校准，不能解释为录用概率。
- 建议有效性缺用户投递/反馈结果，只能报告 `not_evaluated`。
- 当前环境未安装 vLLM，真实 Transformers/vLLM 同硬件 A/B 性能报告待环境具备后执行。

## 刻意不解决

- 暂不把 `server.py` 拆微服务；当前规模下会增加部署与排错成本。
- 暂不建设账号、鉴权、配额、任务队列、在线学习、管理后台和多租户平台；这些不解决当前数据证据问题。
- 暂不新增 CI；本轮使用本地全量测试、静态检查、shell 校验和前端构建收口。
- 暂不自动扩充合成训练数据，也不为 Gold V1 单条错误加特判。
- 不重算或覆盖历史冻结 Gold、报告、预测和审计文件；新回归写新路径并明确语境。
