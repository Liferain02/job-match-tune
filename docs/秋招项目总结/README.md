## 当前结论

1. 产品不是“让大模型直接给匹配分”，而是“JD/简历结构化抽取 + 确定性规则评分 + 大模型解释”的可审计人岗匹配原型。
2. 正式 Gold V1 有 25 条，全部人工复核且与训练集五类重叠均为 0；Product Final 的匹配等级和方向准确率均为 0.96。
3. 当前瓶颈不是模型能力，而是训练数据证据：Resume SFT 的 98.75% 来源组来自 bootstrap；4,798 个 Match Pair 全部是规则合成；显式年限样本 1,944 条全部为“不满足”。
4. 因此 Resume、Match、Multitask 的 readiness 都是 `false`。在获得合法、独立、去标识化的真实数据之前，不继续训练，不以扩大合成数据规模冒充产品进展。
5. 2026-08-13 使用冻结预测重放当前规则后，Gold V1 六项结构指标均为 1.0，但这是 `REGRESSION AFTER INSPECTION`，不是新的盲测；旧解释的结构一致率为 1.0、证据 grounding 为 0.92，建议有效性仍未评估。历史 Gold、报告、预测和隔离审计哈希均未改变。

## 长期审查闭环

后续不设置“为了有下一步而有下一步”的功能清单。每当出现新数据、新模型或规则变更，只循环执行以下最小闭环：

1. 准入：检查许可、来源、隐私、内容去重和任务适配性。
2. 建池：以来源实体分组，先划分再配对，记录可追溯元数据。
3. 审计：检查来源集中、条件分布、真实 Pair 证据和跨集合泄漏。
4. 门禁：只有 readiness 全部通过，才允许训练。
5. 评测：冻结数据、代码、模型和报告哈希，逐层比较 Raw、Normalized、Product Final。
6. 决策：只有独立 Gold 的业务指标提升才进入产品；否则记录为无收益实验。

这个循环可以长期运行，但不会自动扩张产品范围，也不会绕过数据证据门槛。
